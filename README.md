# my-ai-agent-context-trial

A demonstration repository for GitHub Copilot AI agent context features.

## Overview

This repository showcases how to configure and use AI agent context with GitHub Copilot to enhance code generation, suggestions, and development workflows.

## AI Agent Context Files

This repository includes comprehensive AI agent context specifications:

- **[`.github/copilot-instructions.md`](.github/copilot-instructions.md)**: Primary instructions for GitHub Copilot
- **[`.github/AI-AGENT-CONTEXT-SPEC.md`](.github/AI-AGENT-CONTEXT-SPEC.md)**: Detailed specification and best practices

## What is AI Agent Context?

AI agent context provides instructions and guidelines to AI coding assistants, helping them:
- Understand project structure and conventions
- Generate contextually appropriate code
- Follow project-specific patterns and practices
- Provide more accurate suggestions

## Getting Started

1. Review the [AI Agent Context Specification](.github/AI-AGENT-CONTEXT-SPEC.md)

## Benefits

- **Faster Development**: More accurate completions save time
- **Better Onboarding**: New contributors get instant context
- **Quality Improvement**: AI understands project requirements
